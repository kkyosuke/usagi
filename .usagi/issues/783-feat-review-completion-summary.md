## 目的

差分を読む前に、変更の意図と確認範囲を短時間で把握できるようにする。
出典は 2026-10-16 に共有された対応候補一覧の項目 6。

## 対応範囲

- Agent の完了報告に「意図・変更点・確認したこと・懸念」を持つ定型のレビュー要約を設ける。
- 要約を session・Agent run・対象 commit に結び付け、Diff の先頭に表示する。
- 確認したことには実行した検証と結果、未実行の検証を記録できるようにする。
- 要約が長い場合は折りたたみ、未提供・形式不備・対象 commit 更新を明示する。
- 既存の自由文による完了報告を引き続き受け付ける。

## 受け入れ条件

- [ ] 4 項目の要約を完了時に記録でき、対象 Diff の先頭で確認できる。
- [ ] 古い run／commit の要約を現在の変更の確認結果として表示しない。
- [ ] 未提供や項目不足があっても既存の完了報告経路を壊さず、欠落を表示する。
- [ ] 要約と関連付けが再起動後も復元され、保存量・表示量に上限がある。
- [ ] 報告の互換性・対象更新・表示をテストし、実装時に完了報告と TUI の仕様を更新する。
