## 目的

画面や session を何度も切り替えず、移動先と利用可能な操作を一つの入力から探せるようにする。
出典は 2026-10-16 に共有された対応候補一覧の項目 L。画像の評価は実現性「高い」、規模「中」。
ほぼ TUI 内で完結し、既存の操作体系との整理が主な作業となる。

## 対応範囲

- 開いている workspace の session・Agent／terminal タブと、利用可能な既存 command を横断検索する。
- 候補に種類・workspace／session・操作内容を表示し、同名の対象を区別する。
- 既存の Overview／Closeup palette の command 定義と実行経路を再利用する。
- キーボードで検索・候補選択・実行・キャンセルできるようにする。
- 選択確定時に対象の存在と実行可否を再確認し、危険な操作の既存確認を維持する。

## 受け入れ条件

- [x] 一つのパレットから session／タブの移動と既存操作の検索ができる。
- [x] 同名の対象を所属で区別でき、検索中に対象が消えても別対象へ誤実行しない。
- [x] 候補なし・無効な操作・狭い画面でも操作を完了またはキャンセルできる。
- [x] キー入力を背面の PTY へ漏らさず、既存 palette とショートカットが衝突しない。
- [x] 検索・選択・実行可否をテストし、実装時に TUI とキーバインドを更新する。

## 実装

`Ctrl-O k` で開く。コマンドは既存の入力画面に引き継ぎ、次の Enter で実行する。
タブは各 project の表示時に観測したメタデータを検索し、移動時に内部 ID と利用可否を再確認する。
検索対象・入力所有・復元待ちの仕様は [横断コマンドパレット](../../document/03-tui.md#横断コマンドパレット) を参照。
