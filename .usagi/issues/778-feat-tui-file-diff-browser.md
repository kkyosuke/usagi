## 目的

変更全体を一続きの Diff として読む負担を減らし、ファイル単位でレビューできるようにする。
出典は 2026-10-16 に共有された対応候補一覧の項目 1。

## 対応範囲

- 左に変更ファイル一覧、右に選択ファイルの差分を表示する。
- ファイル切替と前後の hunk への移動をキーボードで行えるようにする。
- ファイル単位の viewed（閲覧済み）を設定・解除し、未確認ファイルを判別できるようにする。
- 比較元・比較先を表示し、viewed を session とレビュー対象の差分に結び付ける。
- 対象ファイルの内容が更新された場合は古い viewed を引き継がず、再確認が必要な状態にする。

## 受け入れ条件

- [ ] 複数ファイルの変更を一覧から選択し、選択ファイルだけの差分を確認できる。
- [ ] hunk 間の移動、viewed の設定・解除、未確認ファイルの把握ができる。
- [ ] タブを開き直しても同じ対象の viewed を復元でき、差分更新時は対象ファイルの状態を見直す。
- [ ] 追加・削除・rename・binary・差分なしを扱い、表示できない内容には理由を示す。
- [ ] 狭い端末や大きな差分でも操作可能で、取得・描画・保存に上限を設ける。
- [ ] 差分更新と viewed の失効をテストし、実装時に TUI 仕様とキーバインドを更新する。
