## 目的

動作が止まった可能性のある Agent を見つけ、人が状況を確認できるようにする。
出典は 2026-10-16 に共有された対応候補一覧の項目 G。画像の評価は実現性「高い」、規模「小」。
主な検討点は「止まった」と判断する基準であり、規模は検知基準の設計後に見直す。

## 対応範囲

- daemon が持つ Agent の生存・終了・中断情報と、観測可能な活動情報を使う。
- 確認できた停止と、一定時間進捗を観測できない停滞候補を区別する。
- 長いテスト・推論中の無出力、人への判断待ち、観測失敗を停止と断定しない。
- 判定に使う情報、閾値、解除条件を決め、Attention に理由と最終観測時刻を表示する。
- 検知だけで Agent を自動終了・再起動せず、対象への移動と状態確認を可能にする。

## 受け入れ条件

- [ ] 停止・停滞候補・判断待ち・観測不能を区別して表示できる。
- [ ] 無出力だけでは停止確定にせず、検知理由と閾値を説明できる。
- [ ] 活動再開時には停滞候補を解除し、終了・中断の既存表示と矛盾しない。
- [ ] 同じ状態で通知を繰り返さず、古い Agent identity の結果を再利用しない。
- [ ] 注入した時刻による判定・長時間処理・観測失敗をテストし、実装時に仕様を更新する。
