## 問題

追加指示は「レビューを催促する」「同じ観点で再確認して」のように似た文面の繰り返しになりやすいが、
入力欄は送信のたびに空になり、過去の指示を参照する手段が無い。run は `instructions` を durable に
保持しているので、材料は既にある。

## 方針

- 入力欄が空のときの上方向キーで直前の指示を呼び出し、さらに遡れるようにする。
- 呼び出した内容は編集してから送信できる。編集中の下書きを破棄しない。
- 履歴スクロール（PageUp / PageDown）と競合しない割当にする。
- 呼び出し対象はその session の run の指示に限る。

## 受入条件

- [ ] 入力欄が空のときに過去の指示を遡って呼び出せる。
- [ ] 編集中の下書きを失わない。
- [ ] 履歴スクロールと衝突しない。
- [ ] `document/11-keybindings.md` と `document/03-tui.md` を更新する。
