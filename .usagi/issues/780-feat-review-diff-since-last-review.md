## 目的

Agent の追加修正後に全差分を読み直さず、前回レビュー以降の変更を確認できるようにする。
出典は 2026-10-16 に共有された対応候補一覧の項目 3。

## 対応範囲

- 利用者が明示的にレビューした commit SHA を session／対象 PR ごとに保存する。
- 「全体の差分」と「前回レビュー以降」を切り替え、比較元・比較先の SHA を表示する。
- 差分を開いただけでレビュー済み commit を更新しない。
- 未コミット変更がある場合は commit 済みの比較と区別し、未コミット分をレビュー済み commit に含めない。
- rebase・force push・commit 消失により比較元が現在の履歴と合わない場合は理由を示し、基準の選び直しを可能にする。

## 受け入れ条件

- [ ] commit A をレビュー済みにした後、commit B への追加差分だけを表示できる。
- [ ] タブや TUI を再起動してもレビュー基準を復元でき、別 session／PR の基準と混ざらない。
- [ ] 初回レビュー・追加差分なし・未コミット変更ありを区別できる。
- [ ] 履歴の書き換えや比較元取得不能を「差分なし」と誤表示しない。
- [ ] 全体差分へ戻して再確認できる。
- [ ] SHA の更新と失効・履歴書き換えをテストし、実装時に TUI 仕様を更新する。
