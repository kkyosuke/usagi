## 目的

レビューできる session を探す手間を減らし、マージに近いものから確認できるようにする。
出典は 2026-10-16 に共有された対応候補一覧の項目 4。

## 対応範囲

- 既存の workspace 横断 Attention（#777）に、Agent 完了・Draft PR あり・CI 結果ありの session をレビュー候補として表示する。
- CI の成功／失敗／実行中／未取得、競合の有無、未解決指摘を表示する。
- マージに近い候補を上に並べる。並び順の規則と同順位の順序を定義し、阻害要因を読めるようにする。
- 現在の PR head に対応しない CI 結果は古い結果として扱う。
- 対象 session・Diff・PR へ移動する導線を設ける。
- ローカルレビュー指摘との接続を用意し、未取得の指摘件数をゼロと見なさない。

## 受け入れ条件

- [ ] 候補条件に合う session が既存 Attention の中で重複なく見つかる。
- [ ] CI 成功・競合なし・未解決指摘なしの候補を、阻害要因がある候補より優先して表示する。
- [ ] CI 失敗／実行中、競合あり、未解決指摘ありの理由が分かり、同じ snapshot で順序が安定する。
- [ ] Agent の再開、PR head 更新、マージ・クローズに追従して候補と順位が変わる。
- [ ] 未取得・取得失敗・古い CI 結果を成功や「問題なし」と扱わない。
- [ ] 既存の判断待ち・停止通知を維持し、候補分類・並び替えをテストする。
- [ ] 実装時に Attention と PR 表示の仕様を更新する。
